# Monet v0.1.0 — release draft

Monet is a local workspace for the design decisions behind your UI. Keep principles,
tokens, component choices, and patterns in files you own, and give coding agents the
relevant guidance through the Model Context Protocol (MCP).

## Define → Retrieve → Build → Review

- Edit principles, foundations, component decisions, patterns, and themes in a local UI.
- Retrieve compact, task-specific design context with deterministic matching and links
  to the full records.
- Resolve semantic tokens in light and dark modes, with product theme overrides.
- Preview the system and export portable Markdown, JSON, YAML, and token views.
- Check caller-supplied implementation evidence against token scales, component
  decisions, and contrast contracts through `review_design_usage`.
- Connect any compatible local stdio MCP client. Three read-only tools and resources
  work without the UI or an AI provider running.
- Start from the bundled example or point `MONET_ROOT` at your own directory.

## Get started

Use Node 22.13 or later and pnpm 11.18.0.

```bash
git clone https://github.com/arieskg/monet.git
cd monet
pnpm install
pnpm dev
```

Open http://127.0.0.1:43140. Copy the example before editing it, then use **Agent
context** for MCP setup. The [README](../../README.md) walks through both steps.

## What 0.1 means

This is an early public release for local use. Workspace formats and interfaces may
change; keep your workspace in version control. Monet is distributed as a clone-and-run
application, not a published npm package or hosted service.

Review measures only the evidence submitted. It does not scan source code, judge visual
layout, or establish correctness from an absence of findings. The [MCP guide](../MCP.md#limitations)
details what can and cannot be checked.

The starter is an opinionated example, with deliberately undecided concepts. Some setup,
including a new foundation or component taxonomy, requires editing files or copying the
starter. Primitive and token-registry pages remain intentionally hidden; their records
and exports remain active.

Optional source mapping and reference analysis require a configured local AI CLI or
wrapper matching Monet's current invocation contract. They are off by default and may
send data to the configured provider. Core editing, retrieval, validation, and review
need no model or provider.
