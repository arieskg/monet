# icon-button: none → ant-design

Use Ant Design's icon-only Button as the primary inspiration because it provides a compact, familiar action treatment that fits Monet's dense and restrained interface direction. Icon buttons should minimize visual weight while remaining clearly interactive, accessible, and predictable. The icon communicates the action visually, while the accessible label and tooltip preserve clarity for users who may not recognize the symbol immediately.
